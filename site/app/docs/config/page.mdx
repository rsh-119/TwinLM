# gateway.toml reference

TwinLM reads two kinds of configuration, deliberately kept apart:

- **`gateway.toml`**: behaviour. Providers, aliases, routing, timeouts, prices, cache, limits, guardrails. This page.
- **Environment / `.env`**: secrets and deployment switches. See [Environment variables](/docs/environment/).

Provider keys never go in `gateway.toml`: a provider names the environment setting that holds its key.

**Changes from the console** are stored in the database and layered on top of this file at runtime: providers
added in the console sit next to the file's providers (names can't clash), a model set in the console replaces the
file's model of the same name, and console prices add to or override the file's. Deleting a console model or price
brings back the file's version. See [Providers](/docs/providers/#adding-a-provider-from-the-console). The file is
validated at startup, so a typo or an unknown field fails immediately with its name instead of on the first
request. The path is set by `GATEWAY_CONFIG_PATH` (default `gateway.toml`; in the container, `/app/gateway.toml`).

## Complete example

```toml
request_timeout_seconds = 60
routing_strategy = "priority"         # priority | latency | cost | load
default_max_output_tokens = 4096

[retry]
max_retries = 1
backoff_base_seconds = 0.2
backoff_max_seconds = 2.0

[circuit_breaker]
failure_threshold = 5
cooldown_seconds = 30

[providers.gemini]
type = "gemini"
default_model = "gemini-flash-latest"
api_key_setting = "gemini_api_key"
timeout_seconds = 30
capabilities = ["chat", "tools", "vision"]

[providers.groq]
type = "openai_compatible"
base_url = "https://api.groq.com/openai/v1"
default_model = "openai/gpt-oss-20b"
api_key_setting = "groq_api_key"
capabilities = ["chat", "tools"]

[deployments.gemini-embedding]
provider = "gemini"
model = "gemini-embedding-001"
capabilities = ["embeddings"]

[models.auto]
targets = ["gemini", "groq"]
description = "Default: Gemini, falling back to Groq"

[models.fast]
targets = ["groq/openai/gpt-oss-20b", "gemini/gemini-flash-latest"]
cache_ttl_seconds = 3600

[models.embed]
targets = ["gemini-embedding"]

[pricing."gemini/gemini-flash-latest"]
input_per_million = 0.30
output_per_million = 2.50

[pricing."groq/openai/gpt-oss-20b"]
input_per_million = 0.075
output_per_million = 0.30

[pricing."openai/gpt-4o"]
input_per_million = 2.50
output_per_million = 10.00

[savings]
baseline = "openai/gpt-4o"

[rate_limits]
# default_rpm = 60
# default_tpm = 100000

[cache]
enabled = true
ttl_seconds = 300
max_entries = 1000

[guardrails]
max_input_chars = 200000

[guardrails.input]
secrets = "block"
pii = "log"
prompt_injection = "log"

[guardrails.output]
secrets = "redact"

[structured_output]
max_repair_attempts = 1
```

## Top level

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `request_timeout_seconds` | number > 0 | `60` | Total deadline for one request across retries and fallbacks |
| `routing_strategy` | `priority` · `latency` · `cost` · `load` | `priority` | How deployments are ordered ([Routing](/docs/routing/#routing-strategies)) |
| `default_max_output_tokens` | integer > 0 | none | Output cap for every request ([Output caps](/docs/output-caps/)) |
| `max_stream_output_chars` | integer > 0 | `250000` | Upper bound on a streamed reply's length |

## `[retry]`

| Key | Default | Meaning |
| --- | --- | --- |
| `max_retries` | `1` (0–5) | Retries on the same deployment before moving on. 429s skip straight to the next target |
| `backoff_base_seconds` | `0.2` | Base of the exponential backoff (full jitter) |
| `backoff_max_seconds` | `2.0` | Upper bound of one backoff wait |

## `[circuit_breaker]`

| Key | Default | Meaning |
| --- | --- | --- |
| `failure_threshold` | `5` | Consecutive availability failures that open a provider's circuit |
| `cooldown_seconds` | `30` | How long an open provider is skipped before a trial request |

## `[providers.<name>]`

One block per endpoint + credential. The `<name>` is what you use in targets (`<name>` or `<name>/<model>`).

| Key | Type | Default | Meaning |
| --- | --- | --- | --- |
| `type` | `gemini` · `openai_compatible` · `mock` | required | Adapter |
| `default_model` | string | required | Model used when a target names just the provider |
| `base_url` | URL | Gemini's API for `gemini` | Required for `openai_compatible` |
| `api_key_setting` | string | none | Name of the env setting holding the key: `deepseek_api_key` reads `DEEPSEEK_API_KEY`. Omit for keyless servers |
| `timeout_seconds` | number > 0 | `30` | Per-attempt timeout |
| `capabilities` | list of `chat` `tools` `vision` `embeddings` | adapter default | What this provider's models can do |
| `enabled` | bool | `true` | `false` skips the provider |
| `mock_latency_seconds` | number | `0` | `mock` only: simulated latency |
| `mock_failure_rate` | 0–1 | `0` | `mock` only: share of simulated failures |

See [Providers](/docs/providers/) for ready-made blocks.

## `[deployments.<id>]`

A named provider + model with its own capabilities. Ids must differ from provider and alias names.

| Key | Meaning |
| --- | --- |
| `provider` | A configured provider name |
| `model` | The provider's model name |
| `capabilities` | Overrides the provider's capabilities for this model |

## `[models.<alias>]`

What clients send as `model`. Set **exactly one** of `targets` or `groups`.

| Key | Type | Meaning |
| --- | --- | --- |
| `targets` | list of strings | Ordered fallback. Each entry is a deployment id, `provider/model`, or a bare provider |
| `groups` | list of lists | Model groups: deployments of the same model, tried before falling back to the next group |
| `description` | string | A note for people reading the config |
| `max_output_tokens` | integer > 0 | Output cap for this alias, overriding the default |
| `cache_ttl_seconds` | number ≥ 0 | Cache lifetime for this alias; `0` = never cache |

## `[pricing."<provider>/<model>"]`

| Key | Meaning |
| --- | --- |
| `input_per_million` | USD per million input (prompt) tokens |
| `output_per_million` | USD per million output (completion) tokens |

Models without an entry are tracked with unknown cost. The `cost` routing strategy puts them last.

## `[savings]`

| Key | Meaning |
| --- | --- |
| `baseline` | `provider/model` you would otherwise use for everything. Must have a `[pricing]` entry. Enables `/admin/savings` |

## `[rate_limits]`

Defaults for keys that don't set their own limits; omitted = unlimited.

| Key | Meaning |
| --- | --- |
| `default_rpm` | Requests per minute per key |
| `default_tpm` | Tokens per minute per key |

## `[cache]`

| Key | Default | Meaning |
| --- | --- | --- |
| `enabled` | `false` (the shipped file sets `true`) | Turns the exact-match cache on |
| `ttl_seconds` | `300` | Default entry lifetime |
| `max_entries` | `1000` | LRU entry cap |
| `max_bytes` | `16777216` | Total size cap |

### `[cache.semantic]`

Opt-in [semantic cache](/docs/caching/#semantic-cache). Needs `[cache] enabled = true`.

| Key | Default | Meaning |
| --- | --- | --- |
| `models` | `[]` (off) | Aliases that may reuse answers to similarly worded questions |
| `embedding_model` | `"embed"` | Alias or deployment with the `embeddings` capability |
| `min_similarity` | `0.95` | Cosine similarity needed for a hit, 0–1. Lower = more hits and more wrong ones |
| `max_entries` | `1000` | Entries kept per instance |

## `[guardrails]`

| Key | Meaning |
| --- | --- |
| `max_input_chars` | Reject requests whose input is longer (400) |
| `[guardrails.input]` | Map of guardrail → action for input: `secrets`, `pii`, `prompt_injection` → `block` · `redact` · `log` |
| `[guardrails.output]` | Same, for model output |

`prompt_injection` supports `block` and `log`. See [Guardrails](/docs/guardrails/).

## `[structured_output]`

| Key | Default | Meaning |
| --- | --- | --- |
| `max_repair_attempts` | `1` (0–3) | How often the gateway asks the model to fix invalid JSON before returning 502 |

## Applying changes

The file is read at startup. After editing, restart the gateway:

```bash
docker compose up -d --force-recreate gateway
```
